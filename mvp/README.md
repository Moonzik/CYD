# 凑一队 MVP

AI 驱动的短途旅行平台 —— 最小可行版本。核心闭环：**聊天式输入 → AI 生成四要素个性化行程**。

> 对应计划书「阶段 1：MVP·AI 行程生成」。本 MVP 聚焦「AI 行程生成」，智能匹配组队为下一阶段。

## 功能范围（v0.1）

- ✅ 对话式输入：目的地 / 天数 / 预算 / 偏好（自然语言）
- ✅ ≤15 秒生成完整行程，含四要素：
  - 📍 小众打卡点（优先人少秘境）
  - 🚌 交通衔接
  - 🍜 餐饮推荐（贴合偏好与预算）
  - 💰 预算分配（住 / 吃 / 行 / 玩）
- ✅ 每日行程时间线 + 小贴士
- ⏳ 行程可编辑重排、智能匹配组队（下一阶段）

## 快速开始

```bash
cd mvp
node server.js          # 或 npm start
# 打开 http://localhost:3000
```

无需任何外部 API Key 或数据库——行程由本地 POI 引擎生成，可离线运行。

## 目录结构

```
mvp/
├── server.js          # Node 内置 http 服务（零依赖），托管静态 + /api/plan
├── engine.js          # 行程生成引擎：解析自然语言 → 四要素结构化行程
├── data/cities.js     # 城市 POI 数据集（杭州/成都/长沙/西安/重庆/厦门）
├── public/
│   ├── index.html     # 聊天式界面
│   ├── style.css      # 凑一队绿色主题
│   └── app.js         # 前端逻辑（fetch /api/plan）
└── package.json
```

## API

`POST /api/plan`

请求：
```json
{ "text": "杭州，2天，预算800，喜欢小众和美食" }
```

成功响应（节选）：
```json
{
  "ok": true,
  "city": "杭州", "days": 2, "budget": 800,
  "tags": ["niche", "food"],
  "budgetBreakdown": { "stay": 280, "food": 240, "transport": 120, "play": 160 },
  "itinerary": [ { "day": 1, "spots": [...], "food": [...] } ],
  "transport": "...", "tips": [...]
}
```

无城市识别时返回 `ok:false` 并提示补充目的地。

## 输入约定

| 要素 | 识别方式 | 示例 |
|---|---|---|
| 目的地 | 命中内置城市名 | 杭州、成都、长沙… |
| 天数 | `N天 / N日` | 2天 |
| 预算 | `预算800` / `800元` | 预算800 |
| 偏好 | 关键词（小众/美食/拍照/夜生活/人文/户外/咖啡/松弛…） | 小众+美食 |

同输入生成结果稳定（带种子随机）。
