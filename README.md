# 凑一队 🧳

> AI 驱动的短途旅行平台 —— 像聊天一样说走就走，再凑一队同频伙伴一起出发。

一个人不敢去的地方，我们凑一队，就出发了。🌱

---

## 这是什么

「凑一队」是一款面向 18-30 岁年轻人的 **AI 短途旅行平台**。你只需像聊天一样说出目的地、预算和偏好，AI 会在 **15 秒内** 生成一份完整个性化行程；平台再基于兴趣、年龄、出发地与消费偏好，智能匹配 **4-8 名同频年轻人** 组成小团，实现从「规划」到「组队」到「出发」的全链路服务。

**核心价值**：把「定制游的自由」与「跟团游的省心」合二为一。

---

## 为什么需要它

18-30 岁年轻人短途出行需求旺盛，却卡在三道坎上：

| 痛点 | 凑一队的答案 |
|---|---|
| 攻略查找繁琐、做计划累 | 聊天即出方案，15 秒搞定 |
| 独自出行动力不足、易取消 | 一键凑队，有人一起走 |
| 传统大团社交尴尬、人群参差 | 标签匹配，4-8 人同频小团 |

---

## 核心功能

### 1. AI 行程生成（对话式）
输入目的地 / 预算 / 偏好，≤15 秒输出：
- 📍 小众打卡点（避开人从众）
- 🚌 交通衔接（怎么去、怎么串）
- 🍜 餐饮推荐（贴合预算与口味）
- 💰 预算分配（住/行/吃/玩一目了然）

生成后还可微调，AI 即时重排。

### 2. 智能匹配组队
- 匹配维度：兴趣标签 · 年龄 · 出发地 · 消费偏好
- 成团规模：4-8 名同频年轻人
- 全链路：规划 → 组队 → 出行，不跳转到多个 App

### 3. 体验延伸（规划中）
- 行中助手：实时导航、打卡提醒、集体相册
- 安全机制：实名 / 信用 / 行程共享 / 紧急联系
- 口碑沉淀：行程模板可被他人「一键复用 + 改偏好」

## 目标用户

18-30 岁、追求个性化体验、渴望同频社交、偏好短途周末游的年轻群体：
- **周末探险家**：预算有限、爱小众、怕孤单
- **都市解压族**：时间碎、想逃离、重体验
- **同频社交党**：想认识同好、拒绝尴尬

---

## 技术架构（规划）

```
触达层（微信小程序 / H5 / App）
        │
对话交互层 ──> AI 行程引擎（大模型 + 行程规划）
                    │
              数据与检索层（POI / 交通 / 餐饮 / 价格）
                    │
              匹配引擎（兴趣·年龄·出发地·消费 → 4-8 人小团）
                    │
              出行与履约层（行中助手 / 安全 / 评价）
```

- **前端**：微信小程序优先（获客快、零安装），后续补 H5 / App
- **AI 引擎**：大模型做意图理解与行程编排，接 POI/交通/餐饮/价格数据源落地
- **匹配引擎**：标签向量 + 规则/协同过滤，控制成团质量与规模
- **数据**：用户画像库、行程模板库、反馈闭环，越用越准
